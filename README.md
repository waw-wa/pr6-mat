# Практична робота № 11-12 (6): Первинна обробка статистичних даних програмних систем

Цей репозиторій містить програмну реалізацію, графіки та звіт для практичної роботи № 11-12 з дисципліни «Теорія ймовірностей та математична статистика».

---

## Загальна інформація

* **Дисципліна:** Теорія ймовірностей та математична статистика
* **Тема:** Первинна обробка статистичних даних програмних систем: варіаційний ряд, гістограма, емпіричні числові характеристики
* **Студент:** Процюк Д. І., група ТР-25-1
* **Варіанти завдань:**
  * **Блок 1:** Загальне завдання (Обробка незгрупованої вибірки $n=20$ та побудова ECDF)
  * **Блок 2:** Варіант 2 (Використання RAM сервером $N(1024, 128^2)$, $n=200$)
  * **Блок 3:** Загальне завдання (Детекція та фільтрація аномалій за методом IQR / Boxplot)
  * **Блок 4:** Варіант 8 (Лічильники контейнерів Docker, $n=300$)
